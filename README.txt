1. Create a free account at github.com.
2. Create a new repository (private is fine).
3. Upload every file and folder from this project, including the hidden .github folder.
4. Open the Actions tab and wait for Build APK to finish (about 5 minutes).
5. Open the finished run and download citation-generator-apk from Artifacts.
6. Unzip the download and copy app-debug.apk to your phone.
7. Open the APK. Allow installs from unknown sources when Android asks.
